# Dial samples — Abadis savings calculator

Three review variants of the dial calculator for Alireza and Navid.
Built from `dial/index.html` with day/night theme toggle preserved (`data-theme` + `#themeToggle`).

Shared assets (relative from each sample folder):

- `../../common/abadis-common.css`
- `../../common/abadis-common.js`
- `../../fonts/`
- `../../img/`

Mockup JPGs in this folder are reference only and are not linked from the pages.

## Variants

| Folder | Concept |
|--------|---------|
| `1-quiet-hint/` | Soft resting knob glow + quiet Persian hint under dial: «تعداد تخت را بچرخانید» |
| `2-preset-marks/` | Same as 1, plus labeled preset marks (surgery 1000…30000 / beds 10…700) |
| `3-phone-first/` | Same as 2, with larger thumb dial on mobile, more space, calmer savings cards |

Scroll tracks shortened to ~200vh / ~220vh for easier review.
